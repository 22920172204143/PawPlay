## 已观察到的形态

- 近圆形的红色/洋红色双翅壳，表面有暗红至紫色斑点。
- 双壳之间露出明亮的黄色腹部；开口随时间变宽或变窄。
- 黄色小头、蓝绿色眼点、两根黄色卷曲触角。
- 躯体附近有暖色光晕，身后有金黄色星星拖尾。
- 背景为暗色地表碎屑/落叶质感，画面有暗角。
- 移动包含明显停顿、改变朝向和跨屏移动；短时间局部序列中，停止明显平移时仍可见局部形态变化。

视觉属于风格化瓢虫。视频无法证明原作用实时 3D、预渲染贴图还是二维动画；模型背面、精确材质参数和原始灯光也无法由这段压缩视频唯一还原。因此本项目以可观察的投影与动作复现为准。

## 抽帧与测量

抽帧工具：[extract_reference.py](../tools/reference/extract_reference.py)。

本地证据目录均在 `.local/`，不上传 GitHub：

| 目录 | 内容 |
| --- | --- |
| `.local/reference/baseline/` | 1、3、5……29 秒的 15 个完整 PNG，概览图、局部图、元数据和清单 |
| `.local/reference/wing-sequence/` | 5.0–6.4 秒、间隔 0.1 秒的 15 帧，检查局部开合与朝向变化 |

`manifest.json` 记录原文件哈希、请求时间、图像路径和红壳近似包围盒。抽帧时间是请求 seek 时间，实际源帧可有一个帧间隔内的差别。局部图只做裁剪和放大，未生成或补绘不可见细节。

15 个全片采样的红壳近似包围盒宽度为 74–93 px，高度为 73–94 px，长边中位数为 90 px，即 `90 / 720 = 0.125`。此数值来自特定颜色阈值，**不包含完整头部、触角、光晕和星星**，也不是人工精确分割。后续以人工确认的轮廓修正。

已标出便于复核的时段（近似值，不是完成后的运动拟合）：

| 时段 | 可用于检查的现象 |
| --- | --- |
| 1–3 秒 | 从画面下部往右上移动，躯体朝向改变 |
| 5–7 秒 | 虫子位置接近，便于观察局部开合及转向 |
| 9–13 秒 | 左下区域移动、停顿、改朝上方 |
| 15–17 秒 | 左上区域位置接近，适合观察停顿时的细微动画 |
| 19–23 秒 | 向右跨屏，适合后续拟合平移速度与拖尾 |
| 25–29 秒 | 转向后向左上移动 |

目前没有给出可靠的完整翅壳周期、角速度或体长/秒数值。P2/P3 用更密集帧及人工关键点校准，不能从每两秒一个采样倒推出精确运动曲线。
