# 拖尾参考与实现 / revision 11

## 原片中可观察到的特征

本轮逐帧复核原片 1.0–2.3 秒、5.2–6.5 秒、19.0–20.3 秒的连续源帧。证据沿用 `.local/reference/elasticity-r6/` 的三组 40 帧及时间记录，播放片段在 `.local/reviews/p1/reference-r6/`。原片约 29.97 fps，未用低帧率采样推断节奏。

- 星星是金黄、蜂蜜黄色的实心五角轮廓，尖角略钝，边缘柔和，没有长光线或粗描边。
- 星星尺寸大约是虫身宽度的十分之一，上下有变化；朝向和左右偏移并不一致。
- 快速片段通常只看到几颗，形成较短的尾迹；近尾部较清楚，后面的渐淡。慢速片段中明显稀疏，有些时刻没有星星。
- 连续画面显示星星留在经过的位置，随后消散，并非整串随身体刚性转动。视频压缩及背景细节影响边缘与亮度，不据此宣称测出了原作者的精确粒子寿命或着色方法。

## 当前实现

`BugTrail` 在虫子每次 120 Hz 运动步结束后采样尾部位置。粒子使用独立随机数，不改变运动控制器的随机序列；已生成粒子保持世界坐标，转弯后留在旧路径上。暂停动作也暂停粒子时钟；自然减速到低速阈值时停止发射，已有粒子继续消散。

默认星星使用约 0.30–0.54 秒寿命，带少量旋转与横向飘动，逐渐缩小、淡出。泡泡是另一种可选风格：透明中心、彩虹反光边缘和弧形高光，寿命约 0.65–1.05 秒，缓慢上浮并略微变大。这些是根据观感选择的可调参数，不是原片参数的恢复结果。

revision 9 固定速度 2.5 单位/秒的十秒测量中，星星平均存活约 4.3 颗、最多 6 颗；速度 0.3 时平均约 0.46 颗。泡泡相应约 8.4 / 0.93 颗。透明度很低的存活粒子也计入统计，因此实际清楚可见的数量更少。

revision 10 根据用户反馈将星星发射密度提高 50%，线性尺寸提高 40% 至 0.105–0.196；寿命和消散方式不变。同一高速测量中，平均存活约 6.6 颗、最多 9 颗。密度倍率在样式内配置，泡泡仍使用缺省倍率 1；对照测量确认泡泡数量一致。

revision 11 提高泡泡的可见度：沿圆周与径向加入青、蓝、紫、粉、金色渐变；加宽彩色边缘，并增加两段弧形白色反光。中心保留较低透明度，外围局部更亮。使用顶点颜色与透明度模拟彩色膜和反光观感，没有进行动态环境反射或薄膜物理求解。粒子整体色调接近白色，避免进一步压暗网格色彩；尺寸与生命周期沿用 revision 10。

图形由 `tools/art/build_trail_assets.py` 创建矢量网格，没有使用原视频像素制作贴图。`app/src/main/assets/models/insect_trail.glb` 包含两种样式各 24 个可独立淡出的槽位，共享几何，大小约 49 KB；浏览器和 Android 加载同一资产。粒子面朝观察相机，保留场景遮挡关系。

## 按模型选择

每个模型的 profile 中配置 `trail`，不在虫子运动算法里固定效果类型：

| 字段 | 用途 |
| --- | --- |
| `trail.style` | 默认效果：`stars`、`bubbles` 或 `none` |
| `trail.seed` | 此模型拖尾的可复现随机序列 |
| `tail_offset` / `spread` | 尾部发射位置与横向离散范围 |
| `min_speed` / `full_emission_speed` / `rate` | 根据实际速度平滑控制密度 |
| `styles.<样式>.palette_srgb` | 此模型使用的颜色 |
| `styles.<样式>.rate_multiplier` | 该样式的发射密度倍率，缺省为 1 |
| `styles.<样式>.size` / `lifetime` | 尺寸与寿命范围 |
| `styles.<样式>.drift` / `rise` / `spin` / `end_scale` | 飘动、上浮、旋转和消散时的大小 |

当前源配置为 `art/insects/reference_ladybug/model.json`，运行副本为 `app/src/main/assets/profiles/reference_ladybug.json`；两者需同步。预览下拉菜单只临时覆盖样式，不修改模型默认值。后续新增虫子可沿用同一资产，通过自己的 profile 默认选择泡泡或星星。现有资产容量是 24，增大 `max_particles` 时需同时重建对应数量的槽位。

## 验证与边界

- revision 10 的 21 项 Node 检查已通过；本轮重跑受影响的 6 项拖尾检查，覆盖帧率一致性、运动不受效果切换影响、世界坐标轨迹、停留消散、两种生命周期、容量有界及共享资产结构，全部通过。

- Android `assembleDebug` / `lintDebug` 通过，APK 内 profile、虫子模型、拖尾资产与源码产物一致。
- 浏览器中复核星星、泡泡、关闭对比和三维视角，未见控制台错误；Android 手机实际透明混合效果、性能及发热仍需实测。
